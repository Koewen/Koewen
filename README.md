# 本我 / Koewen 👋

南京的自托管爱好者，喜欢慢慢探索有趣的事；偏爱安静，也愿意接触新鲜事物。

## 🛠 在折腾什么

把一堆服务跑在自己机器上，尽量做到**文本与数据不出内网**：

- **本地翻译工作台** —— Vue3 + Element Plus 前端 / Python + SQLite 后端；长文走本机 Ollama 模型，内置多语种离线词典做快路径
- **监控与可观测** —— 用 Beszel 统一看护 Docker 与 WSL 主机
- **检索增强（RAG）** —— 把笔记接入本地嵌入与重排模型，做私有知识库问答
- **媒体自动化** —— Jellyfin + *arr 全家桶；BT 直连出口，代理仅用于资源发现
- **数据库 ER 可视化** —— 用 ChartDB 维护多套 schema，并保留中文表/字段注释

## 🧰 技术偏好

Docker · WSL2 · Ollama 本地模型 · 中文界面优先 · 隐私优先（local-first）
